# Crie um aplicativo para encontrar a palavra mais longa
Neste laboratório, você criará uma função que retorna o comprimento da palavra mais longa na frase fornecida.

Por exemplo, na frase "The quick brown fox jumped over the lazy dog", a palavra mais longa é "jumped", que tem um comprimento de 6.

## Objetivo
Cumprir as histórias de usuário abaixo e passar em todos os testes para concluir o laboratório.

## Histórias de Usuário

Você deve criar uma função chamada findLongestWordLengthque receba uma string como argumento.
A função deve retornar o comprimento da palavra mais longa na string.
Testes:
Esperando :1. Você deve criar uma função chamada findLongestWordLength.
Esperando :2. findLongestWordLengthDeve ter um único parâmetro.
Esperando :3. findLongestWordLength("The quick brown fox jumped over the lazy dog")deve retornar um número.
Esperando :4. findLongestWordLength("The quick brown fox jumped over the lazy dog")deve retornar 6.
Esperando :5. findLongestWordLength("May the force be with you")deve retornar 5.
Esperando :6. findLongestWordLength("Google do a barrel roll")deve retornar 6.
Esperando :7. findLongestWordLength("Googling do a barrel roll")deve retornar 8.
Esperando :8. findLongestWordLength("What is the average airspeed velocity of an unladen swallow")deve retornar 8.
Esperando :9. findLongestWordLength("What if we try a super-long word such as otorhinolaryngology")deve retornar 19.
