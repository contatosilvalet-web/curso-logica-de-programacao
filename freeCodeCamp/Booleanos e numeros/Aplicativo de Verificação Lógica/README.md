# Workshop: Instruções Condicionais e Operadores de Comparação em JavaScript

Este repositório contém o passo a passo prático do workshop sobre controle de fluxo em JavaScript. Aqui você aprenderá a trabalhar com valores **truthy** e **falsy**, instruções condicionais (`if`, `if...else`) e operadores de comparação.

---

## 🎯 Objetivos de Aprendizagem

- Compreender a diferença entre valores verdadeiros (*truthy*) e falsos (*falsy*).
- Utilizar a função `Boolean()` para inspeção de tipos.
- Construir estruturas condicionais com `if` e `else`.
- Avaliar condições usando operadores de comparação (ex.: `>=`).

---
